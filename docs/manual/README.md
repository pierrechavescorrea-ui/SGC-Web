# Manual de usuario de SGC Web (SigWeb)

Este manual explica cómo usar SGC Web. Es la base de conocimiento del **asistente de ayuda** de la app:
el asistente solo responde con lo que está aquí. Si un capítulo no explica algo, el asistente debe
decirlo y no inventar.

Cada capítulo sigue la plantilla [`_plantilla.md`](_plantilla.md). **Regla de mantenimiento:** cuando cambie
una pantalla, se actualiza su capítulo en el mismo cambio.

## Cómo lo usa el asistente
- El encabezado de cada capítulo (`modulo`, `rutas`, `palabras`) permite elegir el capítulo según la
  página donde está el usuario y las palabras de su pregunta.
- Las líneas «> Por confirmar» son dudas abiertas: el asistente no debe presentarlas como hechos.
