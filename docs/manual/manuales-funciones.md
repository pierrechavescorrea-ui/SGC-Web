# Manuales de funciones

## Para qué sirve

La opción **Manuales de funciones** está reservada en el menú de Contexto y liderazgo. La pantalla actual es un módulo vacío.

## Cómo entrar

Abra **Contexto y liderazgo** y elija **Manuales de funciones**.

## Qu? hay en la pantalla

El encabezado identifica el módulo. La pantalla no ofrece lista, formularios, carga de archivos, exportación ni gestión de versiones.

## Cómo hacer…

### Cómo consultar los cargos

1. Abra [Organigrama](organigrama.md).
2. Use **Lista de cargos** para consultar los cargos y ocupantes registrados.

### Cómo buscar un manual ya registrado como documento

1. Abra [Documentos](documentos.md).
2. Busque el código o título del manual en el listado maestro.

## Permisos

Se requiere **Ver** en Manuales de funciones. El módulo se comparte desde Empresa. Organigrama y Documentos tienen sus propios permisos.

## Problemas frecuentes

- Si la pantalla abre vacía, ese es su estado actual. Revise Organigrama para cargos y Documentos para archivos que ya están registrados.

## Preguntas frecuentes

### ¿Dónde está el manual de cargos?

En **Contexto y liderazgo** aparece **Manuales de funciones**. La pantalla todavía está vacía.

### ¿Se dañó la pantalla de Manuales de funciones?

La pantalla actual está reservada y no tiene registros ni formularios.

### ¿Cómo subo el manual de un cargo aquí?

La pantalla no ofrece carga. Si gestiona el archivo como documento controlado, consulte [Documentos](documentos.md).

### ¿Cómo busco quién ocupa un cargo?

Abra [Organigrama](organigrama.md) y use **Lista de cargos**.

### ¿Dónde veo a quién reporta cada persona?

Consulte el diagrama de [Organigrama](organigrama.md).

### ¿Puedo descargar los manuales desde esta pantalla?

La pantalla actual no ofrece descargas.

### ¿Aquí puedo editar las funciones de un cargo?

La pantalla actual no tiene formulario.

### ¿Hay historial de versiones de Manuales de funciones?

En esta pantalla no hay historial. Si el archivo se gestiona en [Documentos](documentos.md), consulte allí sus revisiones.

### ¿Por qué veo «vacío» al pasar por el menú?

Es el aviso del menú para esta pantalla pendiente de contenido.

### ¿Por qué no encuentro Manuales de funciones en mi menú?

Compruebe el permiso **Ver** para ese módulo en su espacio.
